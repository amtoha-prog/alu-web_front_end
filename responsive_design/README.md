# Responsive Design - Techium

Making the Techium homepage responsive with HTML and CSS: flexible containers, media queries, responsive images, a pure CSS mobile menu, and responsive typography.

## Learning Objectives

- Mobile-first design
- Media queries
- Sizes to use for responsive web design
- How to make a website responsive
- Difference between responsive and adaptive design
- CSS units used to make elements flexible


## Breakpoints Used

| Device | Media query |
|---|---|
| Extra large | none |
| Desktop / large | `max-width: 992px` |
| Tablet / medium | `max-width: 767px` |
| Mobile | `max-width: 480px` |
